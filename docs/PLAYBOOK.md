# PLAYBOOK — قواعد منع التكرار (مولدة من سجل حوادث E01-E21)
R01 لا يمر نص C# يحتوي $"..." عبر perl/sed أبدًا — ملف heredoc مقتبس + إدراج سطري.
R02 قبل أي إصلاح: git checkout <آخر commit أخضر> -- الملف. لا ترقيع فوق ترقيع.
R03 للإدراج بعد سطر: perl -n مع print يدوي أو sed 'a\'. للإدراج قبل سطر: perl -p أو sed 'i\'.
R04 المرساة substring فريد بدون مسافات بادئة مخمَّنة — تحقق بـ grep -n أولًا.
R05 بعد أي تعديل كتل C#: حارس توازن أقواس balance=0 وأقواس متتالية dup=0 قبل commit.
R06 على Git Bash/Windows: sed,awk,grep,cat,perl,powershell.exe فقط. python/node بعد command -v.
R07 لا Replace كتلي متعدد الأسطر بدون تطبيع CRLF أولًا وgrep تحقق بعده. الصمت ≠ النجاح.
R08 رفع الإصدار بنمط شامل فقط + طباعة الختم داخل نفس البلوك قبل commit (يمنع حلقة التحديث).
R09 الرسو على بنية ثابتة (^{) لا على حالة متغيرة. وبعد التعديل grep -c لكل إدخال.
R10 أي ملف جديد: قالب usings كامل مطابق لجاره (يمنع CS0246).
R11 مزودات المكتبات: قائمة استبعاد موثقة + اختبار بأسماء حقيقية (يمنع Redistributables).
R12 لا بوابة تعطيل كاملة على مصدر بيانات اختياري — degrade gracefully + سجل أعداد.
R13 خطوات النشر بأداة رسمية (gh) + retry + فشل صريح لا صامت.
R14 سكربتات المستودع تمر بمراجعة أمان: لا --force، لا rm -rf، فحص ERRORLEVEL بعد كل أمر.
R15 أي Win32 API خلف OperatingSystem.IsWindows() أو واجهة IPlatformService.
R16 grep التحقق: -F للنص الحرفي، والتوقع محسوب (تعريفات+استخدامات) قبل التنفيذ.
R17 كل بلوك تعديل يبدأ بافتراض شجرة نظيفة أو يرجعها (git status --porcelain).
R18 التعديل الجراحي الافتراضي = tools/apply.sh (git apply --check أولًا). فشل check = إعادة قراءة الملف وتوليد patch جديد، لا ترقيع الـ patch.
R19 لا push على main بدون مرور tools/check-meta.sh محليًا.
R20 أي ملف > 500 سطر = بند تقسيم (partial أولًا، ثم خدمات).
R21 ScrollViewer طفل واحد دائمًا. قواعد XAML الأساسية تُفحص بقائمة تحقق قبل الرفع.
